Hướng dẫn cài đặt & Kết nối ESP32 với Web

Làm theo đúng 4 bước dưới đây để mạch ESP32 nhận lệnh điều khiển và gửi cảm biến lên trang web này.

Bước 1

Tạo Dự án & Thêm mạch ESP32

Vào mục Quản lý dự án để tạo dự án. Sang mục Quản lý thiết bị bấm + Thêm ESP32 mới để nhận mã Device Token.

Bước 2

Cài thư viện trên Arduino IDE

Mở Arduino IDE → Sketch → Include Library → Manage Libraries → cài thư viện PubSubClient (của Nick O'Leary).

Bước 3

Nạp code mẫu xuống ESP32

Chọn đúng tên mạch ESP32 của bạn ở khung code bên dưới, bấm Copy toàn bộ Code, điền tên Wi-Fi & mật khẩu rồi nạp vào ESP32.

Bước 4

Cấu hình chân GPIO trực tiếp trên Web

Vào mục Điều khiển thiết bị hoặc Giám sát cảm biến → bấm chọn con ESP32 → khai báo chân GPIO bạn đấu nối và dùng ngay.
